# Mixed benchmark v2 (self-built), 2026-10-28

Rules: `benchmarks/mix/v2/RULES.md` (frozen at f0ca38e3; everything not changed there follows v1, `benchmarks/mix/RULES.md`). Samples are the frozen v1 samples. pagesift 0.80.9 is built from 33ff97ab with the release workflow's command; 0.80.0 is the release binary, re-run on the same machine. All tools run with default parameters (the only common change: ask for Markdown where a tool can produce it); every other deviation is listed in `benchmarks/mix/v2/tools.lock.md`. Machine: i7-10700 (8C/16T), 15 GB RAM, GTX 1070. *Score with failures = 0*: every sampled item counts, an item a tool did not finish (timeout, crash, out of memory, empty output, not reached) scores 0. *Common items*: only items every compared tool finished.
