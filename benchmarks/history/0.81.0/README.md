# 0.81.0：按正文判的页面样本

- `RUBRIC.md`：判分规则（U 有用、M 沾边、X 无用），五个方向的查询。
- `labels.jsonl`：1,900 个判过的页面（`topic`、`url`、`label`、`sample`）。`sample` 是来源：
  `focused-0.80` 是 0.80.10 和其后版本聚焦爬取随机抽的 400 页；`focused` 是 61 校录制里聚焦爬取
  抓到的页面里均匀抽的；`bfs` 是广度优先爬取抓到的页面里均匀抽的；`bfs-top` 是广度优先页面里
  按方面相关度排前四分之一里抽的。每个方向各 180 / 60 / 60 页。
- 每页按正文前 1,800 字（加网址、标题）逐页判，不用关键词规则。

用途：衡量页面相关度模型（`crates/pagesift/src/focus/facet.rs`）和两条自适应停止门槛的换算；
不用来拟合参数。学校按名字的哈希分成两半，一半设计、一半验证。
