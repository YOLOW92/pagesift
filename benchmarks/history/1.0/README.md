# PageSift 1.0 measurements

Measured on 2026-11-04 on one 16-thread machine with 15 GB of memory and a GTX 1070. PageSift only; other tools keep the
numbers recorded on the dates shown in each row.

## Run

```bash
# new and old build taking turns, quality and speed
RUN_ID=final benchmarks/history/1.0/regress.sh <new build dir> <old build dir>
# repeat what looked slower, taking turns on which build goes first
benchmarks/history/1.0/repeat.sh 4 crawl rag office
# A2 without rate limits, live-web stages and OCR, new build only
RUN_ID=final benchmarks/history/1.0/regress.sh <new build dir> <old build dir> a2fast wild a3 b5ocr
```

| Stage | Workload | Main metrics |
|---|---|---|
| `v2quality` | A1, A2, A4, B1, B2, B3, B4, B5 frozen samples | completion, F1, olmOCR, structure kept |
| `v2speed` | A2 HTML and crawl replay, B1 PDF, B4 Office, 1 and 16 workers | p50, p95, items/s, peak MB |
| `a2fast` | A2 replay over HTTP with no rate limit | pages/s, completion |
| `b5ocr` | B5 134 scanned pages with OCR, GPU text and CPU formulas | olmOCR score, pages/s |
| `extract`, `dates`, `markdown`, `rag`, `pdf`, `office`, `b3b5` | one dataset each | see the report |
| `crawl`, `wild`, `a3`, `browser` | local origin and live web | pages/s, coverage, peak PSS |

## Notes on the numbers

- Crawl, chunking and Office rows are medians of the four rounds in [`results/final/repeat.txt`](results/final/repeat.txt).
- The live-web stages ran over a phone hotspot on 4G ([`network.txt`](results/final/network.txt)).
- `scale` was not run: `benchmarks/scale/p0` no longer builds against the current crates.
- Tables and charts are generated by `score/publish.py` and `score/charts.py` from
  [`results/final/new/scorecard.json`](results/final/new/scorecard.json).
