# PageSift 0.50 基准评测：D1 正文提取与 Markdown 提纯全量对决报告

## 1. 评测背景与测试方法论

- **硬件环境**: Google Cloud Compute Engine
  - **CPU**: AMD EPYC 9B45 (32 物理核心 / 32 线程，AVX-512)
  - **内存**: 128 GB RAM，NVMe SSD
- **测试标准数据集**: **Web Content Extraction Benchmark (WCXB)** 官方全量 **2,008 篇真实长网页**（覆盖 7 大页面形态：`article`, `documentation`, `forum`, `listing`, `product`, `service`, `collection`）。
- **评测竞品全家桶 (12 款工具同台对决)**:
  - **Rust 阵营**: `PageSift 0.50`, `crw 0.39.0`, `dom_smoothie 0.18.2`, `html-to-markdown-rs 3.18.6`, `htmd 0.5.6`
  - **Python 阵营**: `trafilatura 2.3.1`, `Crawl4AI 0.9.5`, `readability-lxml 0.9`
  - **Go 阵营**: `go-readability (v0.0.0)`, `go-html-to-markdown v2.5.2`
  - **Node.js 阵营**: `@mozilla/readability 0.6.0`, `defuddle 0.19.5`
- **考核核心指标**:
  - **质量指标**: 词级综合 F1 分数、精确率 (Precision)、召回率 (Recall)；
  - **性能指标**: 单页中位耗时 (p50)、平均耗时 (Mean Latency)、p99 延迟；
  - **32 核全并发吞吐**: 多线程压测下的吞吐量极限 (pages/sec)。

## 5. 核心结论与工程洞见

1. **综合 F1 绝对登顶（0.8472）**：在真实世界跨 7 大品类的 WCXB 全量 2,008 篇标准集上，PageSift 综合 F1 稳居全场第一。在保持高召回（0.9437）的同时，成功克服了通用纯规则库（如 html2md/htmd）在正文外杂质过多的顽疾。
2. **速度断层级碾压**：
   - PageSift 单核平均 **1.30 ms**、中位 **0.99 ms**；
   - 对比行业主流的 Python `trafilatura`（26.52 ms）**快 20.4 倍**；
   - 对比热门的 AI 爬虫 `Crawl4AI`（283.38 ms）**快 218 倍**；
   - 对比 Node 官方 `@mozilla/readability`（206.33 ms）**快 158 倍**。
3. **多核算力释放**：32 核全开下，仅耗时 **0.22 秒** 即完成全部 2,008 篇长网页的正文提纯与 Markdown 转换，吞吐突破 **8,833 pages/sec**，为 0.50 树立了坚不可摧的性能护城河！
