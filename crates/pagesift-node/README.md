# pagesift (Node.js)

The npm package `pagesift`: pagesift's Rust engine for Node.js, built with [napi-rs](https://napi.rs).
Prebuilt binaries, so you don't need a Rust toolchain or a headless-browser download.

```js
import { convert, scrape, Scraper, PagesiftError } from 'pagesift'

// HTML you already have -> Markdown (no network)
const doc = convert(html, { url: 'https://example.com/post' })
console.log(doc.markdown, doc.metadata.title)

// Fetch one page (honours robots.txt, rate limits, refuses private addresses)
try {
  const page = await scrape('https://example.com', { formats: ['markdown', 'links'] })
} catch (e) {
  if (e instanceof PagesiftError) console.log(e.code, e.details) // e.g. ROBOTS_DISALLOWED
}

// Reuse connection pools and browsers across many pages
const scraper = new Scraper()
const results = await scraper.scrapeMany(urls, { concurrency: 8 })
for (const r of results) {
  if (r.success === false) console.log(r.url, r.code, r.error)
  else console.log(r.metadata.title)
}
await scraper.close()
```

## API

| Function | Returns | Notes |
|---|---|---|
| `convert(html, { url?, onlyMainContent? })` | `Document` | Synchronous, runs on the calling thread |
| `convertAsync(html, options?)` | `Promise<Document>` | Runs on the libuv thread pool |
| `scrape(url, options?)` | `Promise<Document>` | Uses a shared default `Scraper` |
| `scrapeMany(urls, { concurrency?, ...options })` | `Promise<Array<Document \| ErrorResult>>` | One failure doesn't affect the rest; order matches `urls` |
| `new Scraper(config?)` | | `scrape`, `scrapeMany`, `close()` |

Options use the same camelCase names as `scrapeOptions` in the Firecrawl JS SDK:
`formats`, `onlyMainContent`, `engine` (`auto`/`http`/`browser`), `timeout`, `waitFor`, `headers`,
`includeTags`, `excludeTags`, `ignoreRobotsTxt`, `mobile`, `blockAds`, plus pagesift's `ifNoneMatch` / `ifModifiedSince`.
Anything pagesift can't do raises `UNSUPPORTED_OPTION` instead of being silently ignored
(`includeTags` and `excludeTags` aren't supported yet).

`Document` has the same fields as Firecrawl's (`markdown`, `html`, `rawHtml`, `links`, `images`, `metadata`).
`metadata.pagesift` adds content hashes, the redirect chain, ETag / Last-Modified, the engine used and per-stage timings.

Errors are `PagesiftError` with a `code` that matches the pagesift HTTP API:
`ROBOTS_DISALLOWED`, `ACCESS_BARRIER`, `RATE_LIMITED`, `HOST_COOLDOWN`, `TIMEOUT`, `SSRF_BLOCKED`,
`TOO_LARGE`, `UPSTREAM_ERROR`, `UNSUPPORTED_OPTION`, `INVALID_REQUEST`, `INTERNAL_ERROR`.
pagesift never tries to get around a block: an access barrier is reported with `details` (vendor, kind, confidence), not bypassed.

`Scraper` config: `userAgent`, `allowPrivateNetwork` (off by default), `requestIntervalMs`, `perHostConcurrency`, `maxBrowsers`.

## Platforms

| Target | Status |
|---|---|
| linux-x64-gnu | built and tested |
| linux-x64-musl, linux-arm64-gnu, darwin-x64, darwin-arm64 | configured, built in CI |
| win32-x64-msvc | configured, **not yet verified** |

## Development

```bash
npm install
npm run build        # release build + index.js / index.d.ts
npm test             # node --test, local HTTP server only
node crates/pagesift-node/bench/bench.mjs bench/data/inputs/manifest.jsonl <dir with jsdom, @mozilla/readability, turndown>  # from the repo root
```

`index.js` and `index.d.ts` are generated by `napi build` (types from `src/`, plus `header.d.ts`) and committed.
Benchmark results are in [BENCH.md](BENCH.md).

This crate doesn't use `#![forbid(unsafe_code)]`, because the napi-rs macros generate unsafe code. Our own code here contains no `unsafe`.
