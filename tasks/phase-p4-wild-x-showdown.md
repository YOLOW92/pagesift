## WILD-X 1 极限挖掘战 (Real-World Public Internet Limits)

### 战役定位与核心目标
**单兵极限摸底与韧性攻坚**。直接面向 100,000 个全球真实顶级站点发起并发抓取与正文抽取，全面考核：
1. **真实公网混沌生存**：面对全球异构网络中的 DNS 解析丢包、TLS 握手故障、Cloudflare/Akamai WAF 403 拦截、429/503 背压风暴、301/302 重定向链深坑、超大 DOM 炸弹等，考核 0.60 错误树分类与自愈降级。
2. **128 GB 物理内存绝对防线**：在连续数万级真实公网高并发长连接下，检验 16KB 固定常驻读缓冲与分片流式解耦，验证峰值 RSS 稳居百兆级别（<500 MB），坚决守死 128 GB 防线，达成零 OOM 与零内存泄漏。
3. **端到端纯净 Markdown 产出**：自动多编码转码与流式抽取，统计真实公网正文的纯净 Markdown 净产出率。

## WILD-X 2 真实亿级（100,000,000）公网终极决战 (Real 100M Live Internet Showdown)

### 战役定位与核心目标
**弥补 0.50 历史遗憾，挑战人类爬虫与提取史上的真实亿级大决战**。
直接面向 Tranco Top 1M 权威公网种子驱动的 **100,000,000 个全球真实公网页面** 发起极限长跑：
1. **Zero-Disk Retention（流式无盘极速管道）**：
   - 彻底解除 1 亿网页需 2.5 TB 存储的爆盘死局。全程 16KB 常驻内存环形缓冲，原始 HTML 即抽即释放，磁盘全程稳定消耗 < 500 MB。
2. **128 GB 物理铁笼与竞品熔断机制**：
   - 严格锁定 `RLIMIT_AS = 128 GiB`。Spider 2.53 若在中途因内存泄漏触及 128 GB 触发 OOM，记录其死亡断点，PageSift 0.60 持续单兵突进完成 1 亿大关。
3. **4,096 路全球长连接并发 (32 Shards × 128 并发)**：
   - 充分释放 80 核心 AMD EPYC 算力，挑战持续 4,000 ~ 6,000 p/s 极限公网吞吐。
4. **有效 Markdown 净产出核验**：
   - 剥离 Spider 虚假 200 OK 中的空壳页面，统计真实的有效富文本纯净 Markdown 产出率。
