## WILD-X 1 极限挖掘战 (Real-World Public Internet Limits)

### 战役定位与核心目标
**单兵极限摸底与韧性攻坚**。直接面向 100,000 个全球真实顶级站点发起并发抓取与正文抽取，全面考核：
1. **真实公网混沌生存**：面对全球异构网络中的 DNS 解析丢包、TLS 握手故障、Cloudflare/Akamai WAF 403 拦截、429/503 背压风暴、301/302 重定向链深坑、超大 DOM 炸弹等，考核 0.60 错误树分类与自愈降级。
2. **128 GB 物理内存绝对防线**：在连续数万级真实公网高并发长连接下，检验 16KB 固定常驻读缓冲与分片流式解耦，验证峰值 RSS 稳居百兆级别（<500 MB），坚决守死 128 GB 防线，达成零 OOM 与零内存泄漏。
3. **端到端纯净 Markdown 产出**：自动多编码转码与流式抽取，统计真实公网正文的纯净 Markdown 净产出率。

## WILD-X 2 真实公网竞品终极决战 (Real-World Live Internet Showdown)

### 战役定位与核心目标
**同台竞技、刺刀见红**。在完全相同的 100,000 个真实公网站点、相同 80 核心、相同 128 GB 物理内存隔离下，展开 **PageSift 0.60 vs Spider 2.53 vs PageSift 0.50** 的交叉对决。

### 四大决战维度对比
1. **真实 200 OK 捕获率之战**：
   - 检验 0.60 的 RFC 7230 连接池重试、现代浏览器指纹、Happy Eyeballs 双栈回退，能否彻底找回 0.50 输给 Spider 的 ~10,000 个 200 OK 差距并实现反超。
2. **有效 Markdown 净产出质量之战**：
   - Spider 虽抓取量大，但存在大量无内容、未清洗的空白空壳文档（约 15% 虚假成功率）；0.60 将对其进行“有效 Markdown 净产出（正文 > 100 字节）”的真实质量核验。
3. **长期内存膨胀与暴涨之战 (Memory Bloat & Leak)**：
   - 实测对比 Spider 长周期运行下的内存失控（9 GB ~ 14 GB 暴涨）与 PageSift 0.60 的平稳低内存（常驻百兆级），在 128 GB 限制下验证企业级稳定性。
4. **全真实链路吞吐 QPS 与单页云成本**：
   - 统计三者在相同公网条件下的实际吞吐、P95/P99 延迟与经济效益。
