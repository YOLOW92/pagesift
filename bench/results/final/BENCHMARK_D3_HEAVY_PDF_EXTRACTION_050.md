# PageSift 0.50 基准评测：D3 重型学术与排版 PDF 提纯全量对决报告

## 1. 评测背景与测试方法论

- **硬件环境**: Google Cloud Compute Engine
  - **CPU**: AMD EPYC 9B45（32 物理核心 / 32 线程，AVX-512）
  - **内存**: 128 GB DDR5 RAM，NVMe SSD
- **评测数据集**: **olmOCR-bench 官方全量基准集（共 1,269 篇复杂真实 PDF）**
  - `arxiv_math`: 密集复杂 LaTeX 数学公式与符号排版；
  - `table_tests`: 跨列、合并单元格及财务/学术多行结构化表格；
  - `multi_column`: 双栏、三栏、非对称科学论文阅读顺序拓扑重建；
  - `headers_footers`: 页眉、页脚、页码抑制与正文连续性提取；
  - `long_tiny_text`: 超密集微小字体、法律与附录条款识别。
- **并发与架构要求（全面避免单线程）**:
  - **PageSift 0.50**：采用自研零拷贝多线程提取引擎（`pdf_dir_mt`），32 原生线程并行分配与处理；
  - **Python / C++ 竞品阵营**：采用 `ProcessPoolExecutor(max_workers=32)`，在 32 颗物理核心上全并发调度；
  - **看门狗保障**：统一开启 **120 GB** 内存上限监控。
- **参评竞品全家桶 (6 大引擎同台竞技)**:
  1. **PageSift 0.50**（Rust）：原生流式布局重建与 Markdown 提纯引擎；
  2. **Docling 2.142.0**（IBM，PyTorch / Deep Learning）：业界最新顶尖的 AI 视觉与布局文档理解引擎；
  3. **PyMuPDF4LLM 2.0**（C++ / Python）：目前 LLM 流水线中广泛采用的高性能转 Markdown 库；
  4. **pypdf 6.21.1**（Python）：纯 Python 标准通用 PDF 处理基线；
  5. **MarkItDown 0.1.9**（Microsoft，基于 pdfminer.six）：微软官方文档抽取框架；
  6. **pdfplumber 0.11.10**（Python）：以精准表格抽取见长的专业解析库。

## 4. Tier 2：逆天极限万页级连续流式压测 (10,000-page Chaos Stress Test)

- **场景设置**: 针对 10,152 篇复杂真实 PDF，执行多线程连续流式重压解析，考核高并发吞吐、内存是否有泄漏（Memory Leak）、以及异常 PDF 的自愈能力。
- **压测实测结果**:
  - **总处理页数**: **10,152 篇**
  - **总耗时**: **4.02 秒**
  - **持续吞吐量**: **2,523.7 pages/sec**
  - **单页处理延迟**: **0.396 毫秒**
  - **峰值内存 (Peak RSS)**: **392.1 MB**（平稳维持，无任何内存泄露）
  - **失败/异常数**: **0 / 10,152**（100% 成功提取）
  - **看门狗判定**: **PASSED (FLATLINE MEMORY)**
