# pagesift 0.30.0 全量复测与新老竞品综合对比报告

本次复测严格覆盖 **0.12.0 基础赛道** 与 **0.20.0 六竞品能力套件**，并在样本规模（8,854 个随机真实网页、120 站点 Wild 模拟、`wide` 20,000 页、`huge` 50,000 页、148 个非 UTF-8 多语种网页）与竞品阵容（新增 `htmd`、`html-to-markdown-rs`、`go-readability`、`go-html-to-markdown`、`colly`、`mdream`、`jina-reader`、`crawlee-python` 等 8 个新竞品）上进行了大幅扩展。全流程严格挂载 **12 GiB 内存硬上限**（`MemoryMax=12G`）。
