# Release benchmark run, 2026-10-22

Everything here was run from a fresh clone of the release candidate, with every competitor at its latest version on that day (`results/2026-10-22/versions.md`), freshly fetched pages, and a new random sample. The master seed (`582031230`, from `secrets.randbits`) and every derived seed are in `results/2026-10-22/seed.json`; the Tranco list is `262W9`.

**Machine:** Intel Core i7-10700 (8 cores, 16 threads), 15 GB RAM, Linux 7.0, rustc 1.99.0.
**Timing conditions:** single-thread timings ran with one tool per physical core (CPUs 0–7, hyperthread siblings idle, ONNX Runtime and BLAS pools limited to one thread so no tool could use more than its core); the JavaScript tools on the random corpus ran in batches of 100 pages across hyperthreads, so their per-page times there are slightly pessimistic. Throughput runs had the machine to themselves, except that the messy-site crawl simulation (mostly waiting on simulated latency) overlapped with the start of the HTTP crawl. Every metric states its direction.

Raw score files: [`results/2026-10-22/`](results/2026-10-22/).
