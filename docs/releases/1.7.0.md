# PageSift 1.7.0 Release Notes

> **Release Version**: `v1.7.0`  
> **Release Scope**: Evidence-driven **Resolve** engine (`Graph`, `Check`, `Gap`, `Counter`, `Live`, `Learn`) across Rust, HTTP `/v2/resolve*`, Cluster Gateway, CLI, MCP, C ABI / Go, Python, and Node.js (`v1.6.3 -> v1.7.0`)

PageSift `1.7.0` adds **Resolve** on top of `DataGraph`, `Loop`, and `Context`, turning answers and atomic claims into persistent, auditable, incrementally re-verified `ConclusionRecord` graphs backed by deterministic seven-layer evidence verification, active counterexample search, bounded gap acquisition, Salsa-style early-cutoff live reconciliation, and drift-guarded online calibration.

## Highlights

- **Evidence-Grounded Conclusion Graph & GC-Immune `ResolveStore` (`pagesift-graph`, `pagesift-store`)**: Introduces persistent `ConclusionRecord` entities with BLAKE3 `contentDigest`, `schemaVersion`, `verifierVersion`, `modelId`, monotonically versioned revision history, `ConclusionState` transitions (`Supported`, `SupportedWithQualifiers`, `Refuted`, `Conflicted`, `Insufficient`, `TemporalMismatch`, `CausalUnidentifiable`, `NeedsHumanReview`, `ObservationDegraded`), and `ScopeDependency` / `unitId` inverted dependency indices stored atomically via `AtomicTx` in GC-immune namespace `ns::RESOLVE` (`15`), isolated per tenant and integrated with `Store::existing_tenants()`.
- **Deterministic Seven-Layer `Check` Engine (`pagesift-extract`)**: Decomposes answers while preserving qualifiers, negations, quantifiers, temporal anchors, causal markers, and inline citations (`decompose_claims`). Evaluates each atomic claim with sentence-level paragraph focusing (`focus_paragraph_sentence`) and row-wise table expansion across seven checks:
  1. Subject/entity anchor isolation (filtering generic tier suffixes and sentence punctuation);
  2. Dual-axis temporal validity (`asOf` observation cutoff with zero future leakage + `effectiveAt` validity interval / year matching);
  3. Quantitative normalization covering currency, billing-period (`/mo` vs `/yr`), and canonical unit conversions;
  4. Negation polarity & qualifier omission guarding;
  5. Causal conservatism (distinguishing correlational evidence as `CausalUnidentifiable` from controlled experiments / RCTs);
  6. Independent origin collapse (`originRoot` / `originIndependent`) preventing syndicated mirror inflation;
  7. Citation reachability and logical falsification for comparative superlative counterexamples and same-origin errata.
- **Active `Counter` Search & Scope Audit (`pagesift-extract`, `pagesift-engine`)**: Plans and executes attribute-guarded counterexample probes targeting errata, deprecations, exceptions, and sibling competitive rows, emitting a structured `CounterSearchAudit` that explicitly records open-world vs closed-world boundaries (`absence_is_not_proof: true` for open-world negative existentials).
- **Bounded `Gap` Acquisition & Optional Quote-Grounded `HybridAssisted` Judge (`pagesift-engine`)**: Reuses `Context` `Action` permission boundaries (`allowNetworkAcquisition` default `false`, `allowedHosts`, robots/SSRF, and per-tenant quota budgets) with Howard VOI gating to fetch missing evidence only when explicitly authorized. Optional `HybridAssisted` LLM judgment requires verbatim quote grounding against archived evidence and cannot override deterministic hard refutations.
- **`Live` Incremental Reconciliation (`pagesift-engine`)**: Re-evaluates persisted conclusions against incoming `ContextDelta` / `SyncDelta` updates using dual `unitId` + `ScopeDependency` indices, applying Salsa-style early cutoff on `RelocatedOnly` / `Reconfirmed` updates, marking `ObservationLost` as degraded without false refutation, propagating new-competitor scope expansion to superlative/negative claims, and falling back safely on ABA `InstanceSuperseded` resets.
- **Conservative `Learn` Calibration (`pagesift-extract`, `pagesift-engine`)**: Calibrates confidence scores via PAV isotonic regression strictly on `HardEvidence` feedback (rejecting weak signals and abstaining on cold start), guarded by Page–Hinkley CUSUM drift detection and automatic reset on `verifierVersion` upgrades.
- **Full Surface Parity (`pagesift-api`, `pagesift`, `pagesift-mcp`, `pagesift-ffi`, `pagesift-py`, `pagesift-node`)**: Exposes Resolve across `Engine::resolve` / `resolve_budgeted`, HTTP `/v2/resolve` (`check`, `list`, `get`, `history`, `graph`, `reconcile`, `revalidate`, `events`, read-only `GET /v2/resolve/learn`, `DELETE /v2/resolve/{id}`, plus Cluster Gateway routing and per-key rate limiting), CLI `pagesift resolve`, MCP `pagesift_resolve`, C ABI `pagesift_resolve` (`pagesift.h` / `bindings/go/pagesift.h`), Python `Scraper.resolve` / `aresolve`, and Node.js `Scraper.resolve`.

## Local Resolve Evaluation (`resolve_eval`, E1–E9)

Measured locally via `cargo run --profile release-fast -p pagesift-engine --example resolve_eval` (`Linux x86_64`, Intel Core i7-10700 8C/16T, `15 GiB RAM`, fixed seed `99323613475`, process peak RSS `31.25 MiB`):

- **E1 Claim Verification & Adversarial Traps (`64` cases)**:
  - `baseline_a_keyword_overlap`: `0.8333` false-support rate (lower is better), `0.1667` supported precision, `0.5000` supported recall, `0.0000` refuted recall, `0.8750` citation accuracy (higher is better).
  - `baseline_b_literal_substring`: `0.3333` false-support rate, `0.3333` supported precision, `0.5000` supported recall, `0.0000` refuted recall, `0.8750` citation accuracy.
  - `full_1_7_resolve`: `0.0000` false-support rate (lower is better), `1.0000` supported precision, `1.0000` supported recall, `1.0000` refuted recall, `1.0000` citation accuracy (all higher is better), `0.2500` abstention rate.
- **E2 Syndicated Mirror Collapse (`20` scenarios)**: Naive multi-source counting yields `1.0000` false-support rate on mirrored articles vs `0.0000` with Resolve origin collapse (lower is better), while maintaining `1.0000` true independent multi-source recall (higher is better).
- **E3 Dual-Axis Temporal & Causal Conservatism (`12` cases each)**: `0 / 12` future-evidence leakages under `asOf` (lower is better); stale 2024 benchmark against 2026 present-tense claim drops from `1.0000` false-support (baseline) to `0.0000` (Resolve, lower is better); `1.0000` causal overclaim blocking on correlational studies and `1.0000` recall on controlled experiments (higher is better).
- **E4 Active `Counter` Search & Scope Audit (`20` adversarial errata cases)**: False-support rate drops from `1.0000` (counter off) to `0.0000` (counter on, lower is better) with `1.0000` counterexample recall (higher is better), `0` open-world negative-existential false supports (lower is better), and `1.0000` `absence_is_not_proof` audit compliance (higher is better).
- **E5 Bounded `Gap` Acquisition (local HTTP server)**: `0` network requests when `allowNetworkAcquisition=false`, `0` requests to disallowed hosts, `1` authorized request resolving an initially `Insufficient` claim to `Supported`.
- **E6 `Live` Incremental Reconciliation (`60` persisted conclusions)**: `0` false triggers on `RelocatedOnly` edits (`5` re-evaluations saved via early cutoff), `1.0000` substantive-impact recall, `0.0000` false-trigger rate, `1.0000` new-competitor scope expansion recall, `0` false refutations on `ObservationLost`, ABA fallback verified, completing in `7,504 µs` incremental vs `33,550 µs` full recheck (`4.47x` speedup; latency lower / speedup higher is better) with `1.0000` full-vs-incremental agreement.
- **E7 Conservative `Learn` Calibration**: Cold-start abstention verified; `0 / 40` weak signals accepted (lower is better); across `80` hard-evidence samples, Brier score improves from `0.2942` to `0.2248` (`95%` paired bootstrap difference CI `[-0.1356, -0.0081]`, lower is better); CUSUM detects abrupt accuracy drift in `10` steps; `verifierVersion` bump triggers automatic reset.
- **E8 Core Throughput & Latency (`400` deterministic checks)**: `9,448.4 QPS` (higher is better), `p50 96 µs`, `p95 131 µs`, `p99 161 µs` (lower is better), `31.25 MiB` peak RSS (lower is better).
- **E9 Honest Limitations (`3` heavy metaphorical paraphrases)**: `DeterministicOnly` abstains (`Insufficient`) on `3 / 3` cases with `0` false supports; callers needing recall on abstract paraphrases can opt into quote-grounded `HybridAssisted` mode.
