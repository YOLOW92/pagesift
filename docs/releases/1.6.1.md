# PageSift 1.6.1 Release Notes

> **Release Version**: `v1.6.1`  
> **Release Scope**: Security, tenant isolation, quota/host-policy enforcement, storage corruption resilience, and `[itna]` hardening patch release on the `1.6.x` line (`v1.6.0 -> v1.6.1`)

PageSift `1.6.1` hardens multi-tenant isolation, daily page quota enforcement, `Context` route and corruption safety, and opt-in `[itna]` network/browser boundaries across Rust, HTTP `/v2/*`, CLI, MCP, Python, Node.js, and C ABI without changing public wire formats or breaking existing APIs.

## Highlights

- **Multi-Tenant Identity & API Key Account Separation (`pagesift-api`, `pagesift`)**: Decouples `[[server.keys]].name` (display/logging label only) from logical tenant identity and introduces explicit opt-in `[[server.keys]].account` for multi-key tenant/quota/ITNA-session sharing. Keys without `account` isolate strictly by domain-separated SHA-256 fingerprint (`key-<32hex>`); reserved prefixes (`key-`, `anonymous`, `__http_anon__`) and conflicting limits on a shared `account` are rejected at config load. Unauthenticated HTTP `pagesift serve` emits an explicit startup warning when bound to a non-loopback address.
- **Atomic Daily Page Quota Across Context Action & Loop Sync (`pagesift-api`, `pagesift-engine`, `pagesift`)**: Extends `PageBudget` with RAII `reserve()` / `commit()` / drop-refund leases (`PageLease`) and routes `/v2/context/action` (plus cluster gateway `ClusterEngine`) and `/v2/sources/{id}/sync` through `context_budgeted` / `sync_source_budgeted` so `pages_per_day` is enforced atomically under both sequential and concurrent requests, refunding failed acquisitions.
- **Tenant-Scoped Action Graph & End-to-End `allowedHosts` Guardrails (`pagesift-net`, `pagesift-cdp`, `pagesift-engine`)**: Binds `ScrapeOptions.owner` to the authenticated tenant during `/v2/context/action` direct acquisitions so `DataGraph` writes and cache isolation stay strictly inside the caller's namespace. Enforces `allowedHosts` across Loop sync candidates, every HTTP redirect hop (`301`/`302`/`303`/`307`/`308`), and Chrome CDP sub-requests.
- **Strict Context HTTP Semantics, Checked `changes` Windows & Corruption Resilience (`pagesift-api`, `pagesift-graph`, `pagesift-store`, `pagesift-engine`)**:
  - Rejects conflicting body `action`/`op` fields on fixed `/v2/context/*` routes and unified `/v2/context` with `400 INVALID_REQUEST`.
  - Makes `GET /v2/context/learn` strictly read-only (`400 INVALID_REQUEST` on mutating query parameters) and includes `GET /v2/context/*` under per-key `requests_per_minute` rate limiting while streaming capped unit queries (`load_live_units_limited`, `load_units_as_of_filtered`).
  - Adds `ContextStore::list_deltas_checked` and `StoppingReason::ResyncRequired` so `ActionMode::Changes` reports retention-window gaps, sequence resets/aheads, and ABA instance replacements instead of returning `sufficient`.
  - Eliminates silent corruption overwrites: corrupt `chis` history aborts atomic commits (`Error::Corrupt`), corrupt `clrn` blocks `POST /v2/context/learn` mutations while read-only `search`/`pack`/`action` degrade with `learn_state_corrupt`, and corrupt `cidx` rebuilds from authoritative live units with `context_index_corrupt_rebuilt`.
- **Opt-In `[itna]` Budget, Error, Proxy & Browser Boundary Hardening (`pagesift-itna`, `pagesift-policy`, `pagesift-cdp`, `pagesift-engine`)**:
  - Shares `ITNA_NETWORK_BUDGET` across `discoverScripts` (`discover_script_graph_with_budget`) and inline HTTP iframe expansion so script-heavy pages cannot exceed the per-request navigation budget.
  - Preserves primary `ErrorCode::AccessBarrier` details when browser fallback fails due to infrastructure/browser errors (`details.itna.fallbackError`), propagates actual egress/default-proxy labels into `metadata.proxy_used` on browser fallback (replacing hardcoded `"basic"`), and enforces a single entry deadline shared by `NetworkBudget`, `Attempts`, and outer `timeout_at`.
  - Prevents double browser execution on `engine:auto` thin/403 pages (`Attempts::note_browser_execution` and HTTP `>= 400` upgrade guard), decouples non-challenge Lightpanda/moli rendering from strict Chrome-only ITNA recovery (emitting `itna_non_chrome_no_subrequest_budget`), replaces `IdentityPool` O(N) scan with O(1) lookup + O(log N) idle LRU eviction, and hardens Chrome CDP interception with `Network.setBypassServiceWorker` plus document/iframe/worker `WebSocket`/`WebTransport` blocking so uninterceptable upgrades cannot bypass SSRF, `allowedHosts`, cookie-origin isolation, or `NetworkBudget`.
