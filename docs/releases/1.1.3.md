# PageSift 1.1.3 Release Notes

> **Release Version**: `v1.1.3`
> **License**: AGPL-3.0-only (Commercial licensing available)

Changes since 1.1.2. Speed and quality figures in the README were measured on 1.1.0 and were not measured again for this release.

---

## Compression

- Updated pure-Rust zstd matching, Huffman decoding and encoding buffers. Matching tables are selected using input size and available cache information; small literal blocks retain compact Huffman tables.
- Higher compression levels use distinct search budgets and support matches beyond the previous fixed search window.
- Corrected repeated-offset state when a compressed block falls back to a raw block, and encoding of sparse sequences with large offsets.
- Standard zstd frames, checksums and the existing compression APIs are unchanged. The compression crate remains dependency-free and forbids unsafe code.

## Compatibility

- Verified round trips, decoding of external zstd samples, bidirectional interoperability with the official zstd CLI, output limits and malformed-input tests.
- No configuration changes or data migration are required.
