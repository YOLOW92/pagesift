# PageSift 1.6.0 Release Notes

> **Release Version**: `v1.6.0`  
> **Release Scope**: Evidence-grounded `Context` infrastructure (`Unit`, `Delta`, `Search`, `Pack`, `Action`, `Learn`) across Rust, HTTP `/v2/context`, CLI, MCP, Python, Node.js, and C ABI, plus `yolowhtml` `0.1.2` (`v1.5.6 -> v1.6.0`)

PageSift `1.6.0` adds persistent and inline `Context` compilation on top of `Graph`, `Store`, and `Loop`, keeping document blocks, claims, source independence, temporal validity, and active conflicts traceable from ingestion through token-budgeted prompt assembly.

## Highlights

- **Cross-Version `KnowledgeUnit` Identity & Lineage (`pagesift-graph`, `pagesift-extract`)**: Separates logical `unitId`, state digest (`revisionId`, `contentHash`), physical `location` (`docId`, `resourceKey`, `sourceUrl`, `sourceKind`, byte spans, `pageNumber`, `headingPath`, `codeLanguage`, `tableMeta`), `lineage` (`created`, `unchanged`, `relocated`, `rewritten`, `splitFrom`, `mergedFrom`, `ambiguous`), and `status` (`active`, `unverified`, `withdrawn`, `expired`, `superseded`). Supports `boundedUot` (Patience/exact anchors + entity-guarded bounded entropic Unbalanced Optimal Transport on local candidate subgraphs), `greedyDice`, and `exactAnchorOnly`.
- **Dependency-Governed `ContextDelta`, `IndexVisibility` & Checkpoints (`pagesift-store`, `pagesift-engine`)**: Persists live units, retired history, delta logs, checkpoints, and calibration state in GC-immune namespace `ns::CONTEXT` via `AtomicTx`. Tracks per-unit `AssetDependency` stamps (`lexicalIndex`, `semanticSketch`, `structureIndex`, `graphIndex`), switches automatically between `incremental` and `fullRebuild` on churn or `AssetSpecStamp` changes, enforces ABA-safe `instanceId` replacement, reports `IndexVisibility` (`lagTicks`), and provides idempotent at-least-once consumer `deltas` / `ack` checkpoints.
- **Multi-Strategy Evidence & Temporal `Search` (`pagesift-extract`, `pagesift-engine`)**: Combines BM25 lexical postings, exact code/CLI symbol postings, heading/caption/table-header boosts, `SubjectKey` matching, and a disableable character-trigram semantic sketch (`enableSemanticSketch`). Separates `asOf` observation cutoffs from `effectiveAt` validity windows (including section-heading year anchor inheritance when explicit `validFrom`/`validUntil` metadata is absent), deduplicates syndicated mirrors via `originRoot` / `originIndependent`, co-retrieves opposing `ConflictRecord` variants, and reports six decoupled score dimensions.
- **Budget-Compiled `ContextPack` (`pagesift-extract`)**: Compiles `compiledContext`, structured `sections`, and `provenanceManifest` under `budgetTokens` and `tokenSafetyMargin` using `submodularClosure` (default), `boundedDpp`, `mmrGreedy`, or `topKGreedy` with `edgeSalience` (default), `scoreDescending`, or `documentOrder` ordering. Enforces `MustKeep` table headers/captions, negations/qualifiers/units, and active conflict pairs, reporting `budgetInsufficient: true` when required closures exceed budget.
- **Goal-Oriented `Action`, Gated Coverage & Drift-Guarded `Learn` (`pagesift-stat`, `pagesift-extract`, `pagesift-engine`)**: Implements `context`, `research`, `verify`, `watch`, and `changes` modes that reuse fresh persisted Context with zero network I/O, diagnose gated Good–Turing / Chapman coverage on closed scopes (returning `estimable: false` on open-world, small-sample, or Zipf-skewed scopes), gate bounded acquisition via Howard VOI (`pagesift_stat::decide::value_of_information`) against live 4D `Admission` shadow prices (`Cpu`, `Memory`, `Browser`, `Politeness`), and calibrate verified grounded scores via PAV isotonic regression guarded by Page–Hinkley `CusumPageHinkley` (default) or `BernoulliBocpd`.
- **Full Surface Parity & `yolowhtml 0.1.2` (`pagesift-api`, `pagesift`, `pagesift-mcp`, `pagesift-py`, `pagesift-node`, `pagesift-ffi`, `pagesift-content`)**: Exposes `Context` across `Engine::context`, `/v2/context*`, `pagesift context`, `pagesift_context`, Python `Scraper.context`/`acontext`, Node.js `Scraper.context`, and C `pagesift_context` (`bindings/go/pagesift.h`), and upgrades `yolowhtml` / `yolowhtml-dom` to `0.1.2` (`<table><caption>` preservation, `hidden="until-found"`, `<q>` quotes, and `input_truncated` capture reliability guarding).

## Local Context, Loop & Domain Evaluation (`context_eval`, `loop_eval`, domain benchmarks)

Measured locally via `cargo run --profile release-fast --locked -p pagesift-engine --example context_eval`, `loop_eval`, and the `1.6.0` release binary (`target/release/pagesift`, Linux `x86_64`, Intel Core i7-10700 8C/16T / 1 NUMA node, 15 GiB RAM, fixed seed `95028642840`, `context_eval` peak RSS `42.4 MiB`):

- **E1 Unit Identity Ablation**: `BoundedUot` achieves `1.00` stable identity precision, `1.00` recall (higher is better; `ExactAnchorOnly` `0.75`), `0.00` false inheritance on templated SKU/year swaps (lower is better), `1.00` duplicate ambiguity detection (`GreedyDice` `0.00`), and `1.00` split/merge lineage accuracy at `63.9 µs` mean CPU per reconcile (`ExactAnchorOnly` `86.1 µs`, `GreedyDice` `60.0 µs`, lower is better).
- **E2 Incremental `ContextDelta` Maintenance (`60` resources, `180` units, `720` derived assets)**: Single-document edit completes in `3,440 µs` incremental vs `15,041 µs` full rebuild (`4.37x` speedup; latency lower is better), reusing `710 / 720` assets (`98.6%`, higher is better) and recomputing `10`; `304 Not Modified` reuses `100%` of assets; tokenizer version upgrade switches to `fullRebuild`; crash/reopen recovery, ABA source recreate purge, and out-of-order consumer `ack` idempotency all pass.
- **E3 Multi-Strategy Search**: Achieves `1.00` Recall@5, `1.00` nDCG@5, `1.00` temporal validity switching (`2025` vs `2026`), `1.00` opposing conflict co-retrieval (all higher is better), and deduplicates syndicated mirrors in `independentSourceCount`.
- **E4 Budgeted `ContextPack` Compilation (`192` & `384` token budgets)**: Across all four selectors (`TopKGreedy`, `MmrGreedy`, `BoundedDpp`, `SubmodularClosure`), facet coverage is `1.00` with `100%` retention of table headers, qualifiers/negations, and conflict pairs (higher is better) in `67–225 µs` compile latency (`68–88 µs` for `BoundedDpp`/`SubmodularClosure`/`MmrGreedy` at `192` tokens, `67–112 µs` at `384` tokens, lower is better; `169–170` tokens used at `192`-token budget, `253–294` tokens at `384`-token budget), and reports `budgetInsufficient: true` on an infeasible `12`-token budget.
- **E5 `Action`, Coverage Gating & `Learn` Calibration**: On a closed `200`-item corpus, Good–Turing unseen mass is `0.212` and Chapman estimates `199.1` total items (`95%` CI covers `200`), while open-world and Zipf-skewed scopes return `estimable: false`; VOI gating saves `4` network requests when local Context is sufficient, suppresses low-gain probes under elevated shadow prices, enforces `>= 2` independent sources in `verify` mode, and records `0` host/permission violations (lower is better). Isotonic calibration reduces Brier score from `0.316` to `0.232` (lower is better); after an abrupt `0.70..0.95 -> 0.15` accuracy drop, `CusumPageHinkley` detects drift in `6` observations (`0` stationary false alarms) with `0.216` post-shift Brier (`0.408` unguarded, `0.250` frozen baseline; lower is better).
- **E6 Multi-Core Search + Pack Scaling (`320` queries per level)**: Scales from `2,708.8 QPS` at `1` worker (`p50 361 µs`, `p99 370 µs`, RSS `25.9 MiB`) to `18,417.2 QPS` at `8` workers (`p50 366 µs`, `p99 607 µs`, RSS `27.3 MiB`) and `24,434.4 QPS` at `16` SMT threads (`9.02x` speedup; `p50 576 µs`, `p95 620 µs`, `p99 2,594 µs`, RSS `28.8 MiB`; QPS higher is better, latency/RSS lower is better).
- **E7 Multi-Format Acceptance Flow (`HTML` + `PDF` + `DOCX`, `24` units)**: Verifies initial ingestion, prefix-edit `unitId` stability, duplicate `ambiguous` marking, single-page incremental `ContextDelta` update, reopen + `Store::gc` persistence (`0` lag ticks), `2025` vs `2026` temporal switching, cross-origin conflict preservation, zero-network `Action` reuse when fresh, bounded `watch` acquisition, and `304` / unreliable-capture / GC invariants.
- **Domain & Gate Verification (`1.6.0` release binary)**: HTML → Markdown `1.000` mean F1 across `600` generated documents at `0.24 ms/page` (F1 higher / ms lower is better); PDF → Markdown `0.645` olmOCR score across `1,269` born-digital pages at `2.58 ms/page` (`428.6 files/s` at 16 workers, `207.2 files/s` 1-worker resident server on 144-page subset); Office/e-book `B4` `0.988` hold-out structure kept across `81` files at `210.0 files/s` in-process (`4.76 ms/file`, `274.6 files/s` 16-worker CLI, `17.2 MB` median / `44.7 MB` peak RSS); `DataGraph` A/B on `181` AEB HTML pages `0.841 ms` (`998.7 pages/s`, `graph=off`) vs `2.260 ms` (`355.7 pages/s`, `graph=on`) with single-pass `yolowhtml-dom` reuse, and `StreamingGraphBuilder` `2,942.4 docs/s` (`1,000` docs, `51.5 MB` RSS); `loop_eval` 16-page × 3-tick real archived corpus completes in `772 ms` (`28` HTTP 304 hits, `880` claims); `perf_gate` (`2.18 ms` 100 KB blog, `7.99 ms` 250 KB wiki), `crawl_gate` (`4,831 pages/s`, `58 MB` peak RSS), and `focus_gate` (`91.5%` / `91.8%` `--auto`) all pass.
