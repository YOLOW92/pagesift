# PageSift 1.4.2 Release Notes

> **Release Version**: `v1.4.2`
> **License**: Apache-2.0 (Commercial licensing available)

Correctness, isolation, and resource-bound patch release for the `1.4.x` release line. No wire-breaking CLI, HTTP API, Python, Node.js, or MCP changes are required.

## DataGraph Correctness & Lineage

- **Filtered & chunked evidence realignment:** Realigning DataGraph slices after `queryFilter` or `chunking` uses deterministic block-to-block mapping (`heading_path` compatibility and duplicate-ordinal disambiguation), whole-token boundary matching, and metadata-island field-context verification, keeping `slice.evidence`, `slice.claims[].evidence`, and unambiguous `version.changed_block_ids` consistent without substring false positives.
- **HTTP 304 conditional version lineage:** Conditional `304 Not Modified` responses match request validators (`If-None-Match` RFC 9110 weak comparison / `If-Modified-Since`) and response `ETag` / `Last-Modified` headers against stored version records to recover the exact matched snapshot and diff it against the current predecessor, reporting `validator_mismatch` or `unconditional_not_modified` when no verified snapshot exists.
- **Redirect & duplicate alias hygiene:** Persistent `GraphStore` alias bindings are restricted to corroborated same-host canonical URLs and contiguous same-host permanent redirects (`301`/`308`). Temporary redirects (`302`/`303`/`307`), client redirects, and content-duplicate edges remain in provenance without merging target histories or overwriting foreign alias pointers.
- **Linear CAS version persistence across crawl sinks:** Rejected or exhausted CAS version commits clear `slice.version` and mark the delta so `StreamingGraphBuilder` and job sinks do not synthesize or persist divergent edges. `GraphStore::record_version` validates parent `prev_doc_id` linearity, remains idempotent on replay, and records `snapshot_omitted` when body snapshots are absent.

## Tenant Isolation, Caching & Bounds

- **Result cache scope isolation:** Result cache keys include effective DataGraph options and caller `graphScope` (`local` vs. HTTP tenant/session scope), bypass shared caching when target-site credentials, session state, or browser actions are present, and strip legacy `doc.graph` payloads on non-graph requests.
- **Private target-context graph isolation:** Unauthenticated HTTP requests carrying custom target `headers`, `keepSession`, or browser `actions` derive an isolated private graph tenant scope across `/v2/scrape`, `/v2/crawl`, job persistence, and `/v2/graph/{history,conflicts}` queries.
- **Global DataGraph limit validation & bounded top-K scans:** Request validation enforces `1..=HARD_MAX_*` bounds on global `GraphLimits` fields (`maxNodes`, `maxCitations`, `maxProvenanceEdges`, `maxVersions`, `maxClaimBuckets`, `maxClaims`) alongside engine clamping; `GraphStore::history_bounded` merges multi-alias timelines via a streaming bounded top-K buffer capped at `limit`; in-memory job history queries honor `graph.versions: false`.

## Networking & Concurrency

- **Proxy hostname target SSRF check:** Configured proxy hostnames are exempted from private-IP checks only when establishing the proxy connection itself; target URLs addressing the proxy hostname still undergo standard SSRF resolution checks.
- **Atomic `AdaptiveConcurrencyGate` state:** `limit` and `active` counters are packed into a single `AtomicU64` updated via CAS across `acquire`, `release`, and `set_limit`.

Drop-in patch upgrade from `1.4.1` and `1.4.0`.
