## Overview

Fixes a small bug: `pagesift-cluster` 0.91.0 did not compile with newer stable Rust when warnings are treated as
errors (`RUSTFLAGS="-D warnings"`), because the gateway lease code called `AtomicU64::fetch_update`, which newer
Rust deprecates in favour of `try_update`. It now uses a compare-exchange loop that compiles without warnings on
both newer Rust and the minimum supported Rust 1.89. No behaviour change.

**macOS x86_64 (Intel) is no longer built:** no command-line binary, Python wheel or `@pagesift/node-darwin-x64`
npm package from 0.91.1 on. macOS arm64 (Apple Silicon), Linux and Windows are unchanged. The Intel runners
were slow and often queued, and a timing-based Node binding test failed there intermittently. Intel Macs can
still build from source (`cargo install pagesift --locked`, or `pip install pagesift` from the source
distribution).

The 0.91.0 release builds were not affected (the release workflow does not deny warnings); the macOS CI run on
`main` was. Changes in 0.91.0: [release notes](0.91.0.md).
