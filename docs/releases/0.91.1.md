# PageSift 0.91.1 Release Notes

> **Release Version**: `v0.91.1`
> **Release Date**: 2026-11-03
> **License**: AGPL-3.0-only (Commercial licensing available)

---

## Intel Macs are no longer supported

**From 0.91.1 on, PageSift no longer supports Intel Macs (macOS x86_64).** There is no command-line binary, no
Python wheel and no `@pagesift/node-darwin-x64` npm package for them, and they are not tested. Releases up to
0.91.0 keep their Intel builds. macOS on Apple Silicon (arm64), Linux and Windows are unchanged.

## Fixed

A small bug: `pagesift-cluster` 0.91.0 did not compile with newer stable Rust when warnings are treated as
errors (`RUSTFLAGS="-D warnings"`), because the gateway lease code called `AtomicU64::fetch_update`, which newer
Rust deprecates in favour of `try_update`. It now uses a compare-exchange loop that compiles without warnings on
both newer Rust and the minimum supported Rust 1.89. No behaviour change.

The 0.91.0 release builds were not affected (the release workflow does not deny warnings); the macOS CI run on
`main` was. Changes in 0.91.0: [release notes](0.91.0.md).
