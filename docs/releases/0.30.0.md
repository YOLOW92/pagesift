# pagesift 0.30.0

A Rust engine for acquiring pages, extracting usable content, and delivering incremental collections and verified media archives. All workspace crates and native distributions move from 0.20.0 to **0.30.0** together. The network API keeps its `/v2` routes.

## What changes

- **Controlled navigation:** bounded pure string-helper folding (`const name = (a, b) => a + b` and `function name(a, b) { return a + b; }`) in `pagesift-content::script_links`, reaching 13/13 on controlled navigation while preserving zero non-navigation visits.
- **Metadata & publication dates:** fast metadata-only extraction path `pagesift_content::extract_metadata` (~3x faster at ~0.32 ms/page) and date disambiguation rules (3-component long dates prioritized over 2-component year-month, slash timestamps, title/page fallbacks, and percent-encoded URL digit exclusion), reaching 0.950 F1 on the 1,000-page date benchmark.
- **RAG chunking & QueryFilter throughput:** ASCII token-span fast paths, binary-search token counting over precomputed starts, conditional block/heading scans, and multi-core batch execution across chunking and BM25 QueryFilter workloads.
