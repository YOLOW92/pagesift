# pagesift 0.30.0

A Rust engine for acquiring pages, extracting usable content, and delivering incremental collections and verified media archives. All workspace crates and native distributions move from 0.20.0 to **0.30.0** together. The network API keeps its `/v2` routes.

## What changes

- **Modular Architecture Refactoring:** All 9 oversized files (>1,000 lines) have been split into clean, cohesive submodules (<600 lines each) across `crates/pagesift`, `pagesift-core`, `pagesift-content`, `pagesift-extract`, and `pagesift-stream`. Public APIs, CLI commands, and behavior are 100% backward-compatible.
- **Controlled Navigation (13/13, 100%):** Bounded pure string-helper folding (`const name = (a, b) => a + b` and `function name(a, b) { return a + b; }`) in `pagesift-content::script_links`, resolving dynamic script-generated links to reach 13/13 on the controlled navigation benchmark with zero non-navigation visit leakage.
- **Fast Metadata & Publication Date Extraction:** Added `pagesift_content::extract_metadata` fast path (0.32–0.37 ms/page, 14× faster than `htmldate extensive`), achieving **0.950 F1** (0.904 precision, 0.992 recall) on the 1,000-page human-annotated `htmldate` evaluation benchmark.
- **RAG Chunking & QueryFilter Acceleration:** Replaced linear rescan with binary-search token spans over precomputed starts; BM25 QueryFilter latency reduced to **1.35–2.11 ms/question** (788× faster than `Crawl4AI BM25Filter` at 1,662 ms), with chunking speedups of 1.9×–4.2× across sliding, fixed, and recursive splitters.
- **Expanded Benchmark Corpus & Strict 12 GiB Memory Limit:** Evaluated on 8,854 random live sites, 148 non-UTF-8 encodings, 120 wild sites, 20,000-page `wide` crawl, and 50,000-page `huge` crawl under a strict `MemoryMax=12G` ceiling. In the 50,000-page crawl, `Spider` and `Colly` were terminated by the kernel OOM killer when exceeding 12 GiB, while `pagesift 0.30.0` completed all 49,990 pages in 19.55 s (2,556 pages/s) at **378.8 MB** peak memory.

## Migration

No changes are required for existing HTTP `/v2` or MCP users. Rust crate users upgrading from 0.20.0 should update dependency version strings to `0.30.0`. All module imports from root crate re-exports remain unchanged.
