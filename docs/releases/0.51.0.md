## 🌟 Executive Overview: What's New in 0.51.0

Following the web-scale milestone of 0.50.0, PageSift 0.51.0 directly addresses real-world industrial testing feedback across containerized environments, proxy networks, academic preprint platforms, and incremental crawling pipelines.

### 🚀 Key Highlights

1. **🌐 Full Proxy & Fake-IP / Remote-DNS Egress Support**:
   - Automatically detects and honors standard system proxy environment variables (`HTTPS_PROXY`, `https_proxy`, `ALL_PROXY`, `all_proxy`, `HTTP_PROXY`, `http_proxy`).
   - CLI adds `--proxy <URL>`, Python SDK `ScrapeOptions` and `Scraper` accept `proxy: str`, and REST API supports explicit upstream proxies.
   - Comprehensive proxy protocol support: `http://`, `https://`, `socks5://`, and **`socks5h://`** (remote hostname resolution on the proxy server), fully supporting TUN and fake-IP environments (Clash, Sing-box).

2. **🛡️ Granular SSRF CIDR Subnet Whitelisting**:
   - Replaces the legacy binary `allow_private_network` with a high-performance, zero-dependency bitmask CIDR evaluator (`IpCidr`) supporting IPv4 and IPv6.
   - CLI adds `--allow-cidr <CIDR>`, configuration adds `allow_cidrs = [...]`, and Python `Scraper` accepts `allow_cidrs=["198.18.0.0/15", "10.0.0.0/8"]`.
   - Out-of-the-box support for benchmarking networks, internal enterprise intranets, and RFC 2544 fake-IP ranges (`198.18.0.0/15`).

3. **🔌 Pip Package MCP Entry Point**:
   - `pagesift-mcp` is now installed as a top-level executable entry point alongside `pagesift` when installed via pip.
   - Exposes `python -m pagesift.mcp` and `python -m pagesift mcp` for cross-platform model context protocol server execution.
   - Native PyO3 binding `run_mcp(transport, port)` connects directly to the underlying high-performance Rust MCP server.

4. **🔬 Precision Academic Boilerplate Pruning (arXiv / Preprints)**:
   - Strips lingering non-article boilerplate embedded inside `<main>` containers on academic sites like arXiv (`1706.03762`).
   - Automatically cleans arXivLabs tabs, CORE Recommender, HuggingFace demo widgets, bookmarks, and author endorser blocks, leaving pure paper title, author list, abstract, metadata, and submission history.

5. **⚡ Incremental Scraping & HTTP 304 Conditional Requests**:
   - Added `if_none_match` (ETag) and `if_modified_since` parameters to Python `ScrapeOptions` and `Scraper.scrape`.
   - Python `Document` exposes `not_modified: bool` (`True` when server responds with HTTP 304, with `status_code == 304` and zero body parsing overhead).
   - Published exhaustive practical documentation [docs/incremental-collection.md](../incremental-collection.md) covering Python, Node.js, Rust, and REST API.

## 📦 Upgrading to 0.51.0

### Rust (Cargo.toml)
```toml
[dependencies]
pagesift = "0.51.0"
```

### Python (PyPI)
```bash
pip install --upgrade pagesift==0.51.0
pagesift-mcp --help
```

### Node.js (npm)
```bash
npm install @pagesift/node@0.51.0
```

### Docker (GHCR)
```bash
docker pull ghcr.io/yolow92/pagesift:0.51.0
```
