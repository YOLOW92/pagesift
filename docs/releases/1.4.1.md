# PageSift 1.4.1 Release Notes

> **Release Version**: `v1.4.1`
> **License**: Apache-2.0 (Commercial licensing available)

Hardening, correctness, tenant isolation, and stability fixes for the `1.4.x` release line. No wire-breaking CLI, HTTP API, Python, Node.js, or MCP changes are required.

## Security & Tenant Isolation

- **ChangeTracking isolation:** Change-tracking snapshot keys across CLI, engine, HTTP routes (`/v2/scrape`, `/v2/crawl`, `/v2/batch/scrape`, `/r/`, `/s/`, monitors), and cluster worker RPCs are scoped by server-verified caller identity (`Caller` authentication status + account) or an HMAC/SHA-256 session digest over incoming HTTP `Cookie`, `X-Session-Id`, and `Authorization` headers when authentication is disabled, rather than caller-supplied tags alone.
- **DataGraph multi-tenant isolation:** `/v2/graph/history`, `/v2/graph/conflicts`, `GraphStore`, background crawl jobs, and extract jobs isolate tenant state across both persistent `Store` namespaces and in-memory job tracking, preventing unauthenticated callers or distinct API keys from accessing other tenants' or pre-1.4.1 unscoped store records.
- **Canonical trust boundaries:** Cross-origin HTML `<link rel="canonical">` declarations no longer overwrite resource identity or merge persistent version history without corroboration (same-origin URL, verified redirect chain, `Link: rel="canonical"` HTTP response header, or verified duplicate content). Uncorroborated declarations are retained in provenance with explicit trust status.
- **Proxy SSRF guard:** Explicit per-request/worker proxies (including SOCKS5h remote-DNS mode and browser engine launch arguments) validate non-loopback proxy endpoints and enforce target-host SSRF checks at proxy/browser boundaries without bypassing private-network policy.

## DataGraph Correctness & Resource Bounds

- **Independent output toggles:** Disabling `evidence` in `GraphOptions` no longer suppresses structured `facts` clusters or `conflicts` generation in `StreamingGraphBuilder`.
- **Stable block IDs and filtered chunk alignment:** Changed block IDs computed for version diffs match the formal `DocNode` / block identity rules (shared URL normalization and hash selection). Applying `queryFilter` and `chunking` resynchronizes blocks, `EvidenceSpan` offsets, `ClaimRecord` locations, and `chunk_idx` assignments while marking pruned spans explicitly as `Unaligned` instead of leaving stale byte offsets.
- **Snapshot-bound version lineage & concurrent CAS:** Each persisted `VersionRecord` binds to its own `doc_id` snapshot rather than looking up the resource's latest pointer, and `GraphStore::commit_version` serializes linear history commits via per-resource sequence CAS outside global store locks, computing text diffs outside lock scope and marking missing, oversized, or evicted snapshots explicitly on the resulting `VersionEdge`.
- **Bounded streaming ingestion, persistence & queries:** `StreamingGraphBuilder` enforces crawl-level global budgets and marks truncated summaries with explicit stats and warnings; `GraphStore` uses symmetric uncompressed/compressed blob caps (`MAX_GRAPH_BLOB`) and bounded paginated history/conflict queries; `record_delta` / `record_version` are idempotent on replay and respect `versions: false`.

## Concurrency, Scheduling & Packaging

- **AdaptiveConcurrencyGate:** Replaced missed-wakeup notify patterns with explicit waiter waking (`notify_waiters()` on final permit release / capacity increases) and tightened CAS retry handling on permit acquisition.
- **CPU worker pool:** Published `pending` counters before task queue visibility to eliminate underflow races, skipped unstarted cancelled tasks while still releasing gate permits, and retained bounded in-place execution behavior when capacity permits.
- **`pagesift-office` Cargo features:** Forwarded `default-features = false` properly to `yolowdoc 0.1.1` so `--no-default-features` excludes `yolowzstd` and `yolowsyntax` unless explicitly enabled.

## Upgrading

Drop-in patch upgrade from `1.4.0`. Existing authenticated API tenants read their newly tenant-scoped `GraphStore` prefixes cleanly; unscoped local embedded/CLI/MCP callers keep reading local unscoped data.
