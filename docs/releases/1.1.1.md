# PageSift 1.1.1 Release Notes

> **Release Version**: `v1.1.1`
> **License**: AGPL-3.0-only (Commercial licensing available)

Changes since 1.1.0. Speed and quality figures in the README were measured on 1.1.0 and were not measured again.

---

## Source code

- One section per top-level function or class now covers C, C++, C#, Go, Java, JavaScript, TypeScript, Lua, PHP, Python, Rust, Bash, Ruby, Kotlin, Objective-C, Dart, Julia, OCaml, Elixir, R, Solidity, Pascal, Common Lisp, Groovy, Gleam, PowerShell, CMake, Erlang, D and Elm. When a file's only top-level item is a namespace or module, sections split one level inside it.
- Each included grammar passes its own test corpus. Sources and licenses: `crates/pagesift-syntax/THIRD-PARTY.md`.
- A lexer loop at end of input that could hang on files without a trailing newline is fixed.

## Documents

- `.doc`: numbered lists keep their numbers; headers and footers are added after the body, and comments are prefixed `[comment]`.
- dBASE: memo columns read `.dbt` and `.fpt` with the same name in the same archive directory. A single `.dbf` without them keeps empty memo columns.

## Compression

`pagesift-compress` replaces the C zstd library. It is written in safe Rust and reads and writes the Zstandard format. Existing snapshots stay readable. Compared with the C library at level 3 in one process (three samples, best of 8 runs):

| Metric | Direction | pagesift-compress | C zstd |
|---|---|---|---|
| Compressed size, relative to C | lower is better | 1.011–1.025 | 1 |
| Write, MB/s | higher is better | 130–194 | 237–362 |
| Read, MB/s | higher is better | 488–712 | 1307–1781 |

- Dictionaries are not supported.
- `pagesift-store`: the config field `snapshot_zstd_level` is now `snapshot_compress_level`.
- HTTP clients built on reqwest no longer advertise zstd in `Accept-Encoding`.
- `blake3` no longer builds C or assembly.

## Dependencies

`ring` still provides the cryptography for HTTPS and webhook signatures, and contains C and assembly.

## Release process

- npm: the `pagesift` wrapper waits until `@pagesift/node` is visible in the registry.
- The Go module tag is created during the release.
- `scripts/check_workflows.py` checks workflow files in the local CI.

## Known limits

Support for more file types and source-code languages will be added over time. If you need one, please [open an issue](https://github.com/YOLOW92/pagesift/issues).

- The RubyGems, NuGet and pub.dev packages of 1.1.0 keep their earlier README.
- `.doc`: Word 6/95 is text only.
- WordPerfect for Mac 1.x and 3.x, audio, video, HEIC, JPEG 2000, `.pst`, iWork and RAR are not supported.
