# PageSift 1.3.0 Release Notes

> **Release Version**: `v1.3.0`
> **License**: Apache-2.0

Changes since 1.2.7. This release re-licenses PageSift from AGPL-3.0-only to the **Apache-2.0** license across the Rust workspace, CLI, server, native packages, and container distributions.

## Relicensing to Apache-2.0

- **Permissive open-source license:** PageSift and all sub-crates (`pagesift-*`), native bindings, MCP servers, and language packages (Python `pagesift`, Node `@pagesift/node`) are now licensed under **Apache-2.0**.
- **Commercial & enterprise friendly:** Eliminates network copyleft obligations. Organizations can embed, modify, and deploy PageSift internally or as part of commercial products without requiring network source disclosure.
- **Explicit patent protection:** Apache-2.0 provides an explicit patent grant and protection against patent infringement litigation.
- **Enterprise support & services:** Dedicated SLAs, integration assistance, and priority support remain available via commercial support agreements (see [COMMERCIAL.md](../COMMERCIAL.md)).

## Upgrading

No configuration, CLI, HTTP, or MCP API changes.
