# PageSift 1.5.3 Release Notes

> **Release Version**: `v1.5.3`  
> **Release Scope**: Graph entity isolation, intra-document conflict detection, diagnostic warnings, credential redaction, and HTTP/storage hardening on the `1.5` line (`v1.5.2 -> v1.5.3`)

PageSift `1.5.3` resolves twelve correctness, isolation, diagnostic-reporting, and transport edge cases across `pagesift-extract`, `pagesift-graph`, `pagesift-store`, `pagesift-net`, `pagesift-engine`, and `pagesift`.

## Highlights

- **Same-Origin Canonical & Permanent-Redirect Trust (`pagesift-graph`, `pagesift-store`, `pagesift-engine`)**: Added strict `same_origin` validation (matching scheme, host, and normalized default port) across `DocNode::is_trusted_canonical`, canonical/permanent-redirect provenance edges, and crawl/sync alias resolution. Uncorroborated `<link rel="canonical">` tags and cross-port/cross-origin redirects no longer hijack `resource_key` or `doc_id`, while intra-tick version chaining and deduplication keep sync histories order-invariant.
- **Multi-Product & Multi-Entity Isolation (`pagesift-graph`, `pagesift-engine`)**: Assigned isolated `#json-ld/{idx}`, `#microdata/{idx}`, and `#item/{idx}` subject keys for multi-product pages lacking shared SKUs or `@id` anchors while keeping single-entity pages and boilerplate site metadata unified, preventing unrelated catalog products on one page from generating false price conflicts.
- **Intra-Document Price & Field Conflict Detection (`pagesift-extract`, `pagesift-graph`, `pagesift-engine`)**: Added OpenGraph `product:price:amount` / `product:price:currency` extraction and canonical normalization, included visible HTML table/KV traces alongside structured data when `graph.conflicts` is enabled, computed and persisted intra-document conflicts into `PageGraphDelta`, `GraphSlice`, and `GraphStore`, and refreshed conflict `doc_id` bindings across remap paths.
- **Graph Truncation Disclosure (`pagesift-graph`, `pagesift-engine`)**: Propagated `truncated` and `truncation_reasons` through checked block, citation, and fact-cluster builders onto `PageGraphDelta`, `GraphSlice`, and `GraphStats`, and surfaced `graph_truncated` warnings in both `metadata.pagesift.warnings` and top-level `warning`.
- **JSON-LD, NUL-Byte, PDF Empty-Page & Office Limit Warnings (`pagesift-extract`, `pagesift-engine`)**: Added `malformed_json_ld` diagnostics for unparseable `<script type="application/ld+json">` blocks, `nul_bytes_stripped` detection for literal NUL bytes stripped during HTML parsing, `empty_pdf_pages` risk warnings when significant non-scanned PDF pages produce empty text while overall PDF text is non-empty, and `document exceeds the ` prefix matching in `CONTENT_RISK` so attachment-nesting limit warnings reach top-level `warning`.
- **URL Credential Stripping (`pagesift-engine`)**: Stripped URL `user:pass@` userinfo before building HTML extraction base URLs, `Link` header canonical/alternates, redirect chains, `metadata.url`, `metadata.sourceURL`, `favicon`, extracted links/images, upload parse metadata, and DataGraph `DocNode` records while preserving outbound credentialed fetch/browser requests.
- **Deleted Store Directory Detection (`pagesift-store`)**: Verified backing store directory presence and active segment path + `(dev, ino)` identity before `AtomicTx::commit`, `Tx::put`, `Tx::delete`, `Store::append`, and `Store::flush`, failing immediately with `NotFound` instead of appending to unlinked file descriptors.
- **HTTP/1.1 Header Cap & `--allow-cidr` Clarity (`pagesift-net`, `pagesift`)**: Raised hyper HTTP/1.1 `max_headers` from the default `100` to `2048` so valid responses with hundreds of headers succeed, and clarified `--allow-cidr` CLI help to state that matching subnets apply across all ports.
