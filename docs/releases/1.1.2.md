# PageSift 1.1.2 Release Notes

> **Release Version**: `v1.1.2`
> **License**: AGPL-3.0-only (Commercial licensing available)

Changes since 1.1.1. Speed and quality figures in the README were measured on 1.1.0 and were not measured again.

---

## Fixes

- MCP: the server advertised the `resources` capability but returned `Method not found` for `resources/list`. It now answers `resources/list` and `resources/templates/list` with empty lists; resources remain the links returned by tool results.

## Source code

- Verilog and SystemVerilog are split into one section per top-level module, interface, package, class, function or task. The grammar passes its own test corpus.

## Release process

- Each release publishes `pgo-<target>.profdata`; the next release builds once from it instead of training again.
