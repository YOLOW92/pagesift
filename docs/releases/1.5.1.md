# PageSift 1.5.1 Release Notes

> **Release Version**: `v1.5.1`
> **License**: Apache-2.0 (Commercial licensing available)

Stability, correctness, and platform resource-lifecycle patch release for the `1.5.x` release line. No wire-breaking CLI, HTTP API, Python, Node.js, or MCP changes are required.

## Release & Binding Fixes

- **Node.js `Scraper.close()` handle release (Windows `ENOTEMPTY`):** Wraps the inner scraper core in `RwLock<Option<Core>>` so `scraper.close()` explicitly drops the core and its `pagesift-store` directory lock immediately instead of waiting for V8 garbage collection; directory cleanup in `test/loop.test.mjs` also retries transient platform locks during teardown.

## DataGraph & Evidence Lifecycle

- **Strict temporal semantics & conflict normalization:** `parse_temporal` rejects uncorroborated bare numbers, relative years/durations, and non-calendar out-of-range dates; `normalize_period_token` distinguishes `Annual` from `Monthly`/`OneTime`, maps month tokens cleanly, and detects billing-period mismatches (`annual` vs. `monthly`) in `conflict.rs`.
- **Same-evidence independence & evidence boundary alignment:** `origin_relation` avoids misclassifying third-party cites with overlapping paths on unrelated domains as mirror copies; block/excerpt alignment avoids substring false hits and rejects speculative alignment without an explicit block match.
- **Claim lifecycle timeline & contract inheritance:** `reconcile_resource_claims_for_contract` upgrades `DEFAULT_CONTRACT_ID` claims to the active source `contract_id`, preserves interval-start claims across coalesced unchanged observations, preserves initial `PREFIX_PROV` timestamps across re-observations, and distinguishes `HistoryUnavailable` when bounded timelines truncate before a requested `asOf` timestamp.

## Store Atomicity & Point-in-Time Isolation

- **Atomic sync-tick commit (`AtomicTx`):** Tick inventory, experience snapshot, delta log, prepared graph version/claim bundles, and conflict updates commit via a single staged write transaction paired with CAS revision checking (`expected_spec_revision`) and fault-injection crash verification across segment writes.
- **Bounded history & snapshot offloading:** `GraphStore::history_bounded` uses bounded multi-alias top-K merging; `SyncStore::build_state_view(..., as_of)` reconstructs point-in-time `DataSourceSpec` revisions and inventories isolated from later writes or deletions; monitor checks reject evicted snapshots rather than rewriting baseline history.

## Sync Loop Execution, Scope & Adapt Learning

- **Exact-origin scope & safe redirect migration:** `origin_allowed_by_spec` enforces scheme, host, and port equivalence; `permanent_redirect_target_from_provenance` validates contiguous verified `301`/`308` chains ending at an in-scope target without merging off-scope destinations.
- **Inventory & capture quality guards:** `classify_resource_role` avoids labeling arbitrary depth-1 leaves as hubs; `assess_document_capture` checks per-field grounded evidence and treats `NotModified304` cleanly without downgrading verified content; consecutive `404` tracking resets across `503`/`429` transient failures and clears stale validators on `200`/`304` omissions; `maxRequests` bounds (`1..=10000`) and non-excluded seed checks apply uniformly across HTTP `/v2/sources`, CLI, and MCP interfaces.
- **Bounded tick budgets & non-polluting experience updates:** `TickBudgetLedger` tracks wall clock, total requests, and browser renders strictly inside tick bounds (and pauses cleanly in unit tests); `direct_browser` and network-censored failures no longer update HTTP sufficiency posteriors.

## Upgrading

Drop-in patch upgrade from `1.5.0`.
