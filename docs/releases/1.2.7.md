# PageSift 1.2.7 Release Notes

> **Release Version**: `v1.2.7`
> **License**: AGPL-3.0-only (Commercial licensing available)

Changes since 1.2.6. This release switches `pagesift-base64`, `pagesift-pdf`, `pagesift-html`, and `pagesift-content` from in-tree copies to the upstream MIT-licensed [`yolow64`](https://crates.io/crates/yolow64) `0.3.0`, [`yolowpdf`](https://crates.io/crates/yolowpdf) `0.1.2`, [`yolowhtml-dom`](https://crates.io/crates/yolowhtml-dom) `0.1.0`, and [`yolowhtml`](https://crates.io/crates/yolowhtml) `0.1.0` crates, bringing new AVX2+BMI2 short-input/tail Base64 kernels, streaming decoder fixes, native PDF image Data URL helpers, and unified HTML5 arena parsing and Markdown extraction.

## Upstream `yolow64` 0.3.0, `yolowpdf` 0.1.2, and `yolowhtml` 0.1.0 integration

- **Single source of truth:** `pagesift-base64` re-exports `yolow64` `0.3.0`, `pagesift-pdf` re-exports `yolowpdf` `0.1.2`, `pagesift-html` re-exports `yolowhtml-dom` `0.1.0`, and `pagesift-content` re-exports `yolowhtml` `0.1.0` instead of duplicating source files across repositories.
- **Base64 (`yolow64` 0.3.0):** adds six dedicated AVX2+BMI2 `pext` kernels (`decode12`, `decode24`, `decode44`, `decode88`, `decode_hash4_tail44`, `decode_hash4_tail88`) for short and padded inputs, fixes `Decoder::feed` so a rejected chunk no longer leaves partial bytes in the streaming buffer, and allows `decode_parallel_with_threads` to honor caller-requested thread counts above `available_parallelism`.
- **PDF (`yolowpdf` 0.1.2):** exposes `PdfImage::mime_type()` and `PdfImage::data_url()` (backed by `yolow64` `0.3.0`) on exported PDF images while preserving existing `pagesift_pdf` API compatibility.
- **HTML & Content (`yolowhtml-dom` 0.1.0 & `yolowhtml` 0.1.0):** extracts the zero-copy arena HTML5 parser and single-pass main-content / Markdown / metadata / publication-date engine into standalone MIT crates consumed directly by `pagesift-html` and `pagesift-content`.

## Upgrading

No configuration or HTTP/CLI/MCP API changes.
