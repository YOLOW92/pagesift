# PageSift 1.5.4 Release Notes

> **Release Version**: `v1.5.4`  
> **Release Scope**: Sync JS-shell sufficiency gating, monitor/batch API validation & response contracts, CSV fallback decode warnings, corrupt-format diagnostics, CLI warning propagation, and canonical Graph variant deduplication (`v1.5.3 -> v1.5.4`)

PageSift `1.5.4` resolves seven behavioral correctness, API contract, and diagnostic bugs across `pagesift-plan`, `pagesift-graph`, `pagesift-net`, `pagesift-api`, `pagesift-engine`, and `pagesift`.

## Highlights

- **JS-Shell Sufficiency Gating (`pagesift-plan`, `pagesift-engine`, `pagesift-api`)**: Detects client-rendered JavaScript shells (`empty_content:`, `thin_content:`, executable scripts with empty content or empty `#app`/`#root`/`__next`/`__nuxt`/`svelte`/`app-root` mounts, and loading/enable-JavaScript placeholders) while preserving legitimate short server-rendered pages. JS shells are marked insufficient (`insufficient_captures`, non-active lifecycle state, `baselineSufficient: false`, incomplete coverage status, and browser escalation).
- **Monitor Interval Validation Clarity (`pagesift-api`)**: `POST /v2/monitor` reports the enforced 300-second minimum (`300000` ms) and raised effective `minIntervalMs` whenever `maxIntervalMs` conflicts with the 300s floor instead of contradicting user inputs, and attaches a `monitor_min_interval_raised` warning when sub-300s floors are clamped.
- **Non-UTF-8 Fallback Decode Warnings (`pagesift-net`, `pagesift-engine`)**: Emits explicit `decode:` warnings (including the fallback charset name) into `metadata.pagesift.warnings` and top-level `warning` when invalid UTF-8 CSV or text payloads fall back to an unconfirmed single-byte charset such as `windows-1254`.
- **Batch Cancel JSON Envelope (`pagesift-api`)**: `DELETE /v2/batch/scrape/{id}` now returns a JSON `JobCancelled` envelope (`success`, `id`, `status`) consistent with other endpoints rather than an empty HTTP 200 body; missing job IDs continue to return JSON 404.
- **Corrupt Declared File Diagnostics (`pagesift-api`, `pagesift-engine`, `pagesift`)**: When binary signature sniffing fails on a supported declared extension or MIME type (such as `.epub` or `.sqlite`), PageSift returns `INVALID_REQUEST` pointing to corrupt content or declared-format mismatch instead of `UNSUPPORTED_OPTION` (`"unsupported content type"`).
- **CLI Top-Level & Markdown Stderr Warnings (`pagesift-engine`, `pagesift`)**: Unwraps nested `<member>: ` prefixes in `notice::is_content_risk` (alongside `email_truncated`, `attachments_truncated`, `archive_truncated`, and `mbox_truncated`) so deep EML attachment-nesting warnings print to stderr in CLI markdown mode, and includes top-level `warning` in `pagesift scrape --format json` responses.
- **Canonical Conflict Deduplication (`pagesift-graph`)**: Applies currency/money field normalization to numeric JSON-LD values (`"price": 66` -> canonical `Money`), eliminating same-page `['$66', '66']` false conflicts and merging equivalent raw forms into one variant.
