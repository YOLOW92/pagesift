## 🌟 Executive Overview: What's New in 0.50.0

PageSift 0.50.0 marks the most significant release in the project's history, expanding from local synthetic benchmarks to **Web-Scale Real-World Production**. Version 0.50 establishes complete architectural dominance across **all 10 Evaluation Domains (D1 through D10)** and introduces the **Dynamic Adaptive Resource & Concurrency Tuning Engine**, proven against official global internet datasets (Tranco Top 1 Million).

### 🚀 Key Highlights

1. **🏆 The 100,000 Real-World Showdown: PageSift vs. Spider 2.53.9**:
   - In a head-to-head live public internet battle on a 32-core AMD EPYC server across 100,000 live Tranco domains under identical 768 concurrency:
     - **Memory Footprint**: PageSift sustained **188.4 MB peak RSS** across 105,660 live websites. Spider exploded to **8,978.9 MB (~9.0 GB)** within 2.5 minutes and subsequently hung on socket deadlocks at 14 GB. **PageSift delivers 47.6× lower memory consumption**.
     - **Content Distillation Quality**: PageSift achieved a **96.38% valid Markdown extraction conversion rate** (60,659 valid documents out of 62,937 successful 200 OKs). Spider suffered a **17.2% failure rate** (over 12,400 empty shell documents) due to brittle lexical transformation.
     - **Net Output**: PageSift produced **60,659 rich Markdown documents**, outperforming Spider's 59,803 valid documents.
2. **🧠 Dynamic Adaptive Concurrency & Timeout Engine (`pagesift::adaptive`)**:
   - **Bottleneck-Constrained Model ($\min$ Principal)**: Concurrency is strictly bounded by the intersection of CPU capacity, physical memory safety (2MB/conn), and OS file descriptors (`ulimit -n`):
     $$\text{Concurrency} = \min\big(C_{cpu},\; M_{mem},\; FD_{safe}\big)$$
   - **Hardware Tier Coverage**:
     - **Micro (1C1GB class)**: Concurrency 16, connect timeout 4.5s, RSS < 150MB.
     - **Small (2C2GB ~ 4C4GB class)**: Concurrency 48, connect timeout 4.0s.
     - **Mid Desktop (8C16GB / i7-10700 class)**: Concurrency 200, connect timeout 3.5s.
     - **High-End Server (32C128GB / EPYC 9B45 class)**: Concurrency 768, connect timeout 3.5s.
     - **Extreme Supernode (64C+ 128GB+ FD>=65k)**: Concurrency up to 4,096. Requires strict multi-dimensional qualification, eliminating "high-memory, low-core" VM misclassification.
   - **Dual User Switch**: `--tuning-mode adaptive` (maximum hardware saturation) vs. `--tuning-mode conservative` (strictly keeps CPU < 20% and minimal memory for shared workstations).
3. **🛡️ Complete 10-Domain Benchmark Suite (D1 through D10)**:
   - Full evaluation suite covering Content Extraction, Massive Crawl Chaos & 12GB RAM Defense, Heavy PDF LaTeX recovery, DOM Self-Healing, RAG Semantic Chunking, Adversarial Charset Normalization, Structured Data & Deep Microdata, Implicit JS Endpoint Discovery, Dynamic Headless CDP Rendering, and Resilient AI API Gateways.

```toml

```

### Python SDK
```bash
pip install pagesift==0.50.0
```

### Node.js SDK
```bash
npm install @pagesift/node@0.50.0
```

### Docker
```bash
docker pull ghcr.io/yolow92/pagesift:0.50.0
```
