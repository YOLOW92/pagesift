# PageSift 1.5.6 Release Notes

> **Release Version**: `v1.5.6`  
> **Release Scope**: Final `1.5.x` Loop correctness remediation across Observe, Schedule, Adapt, Evidence, and `loop_eval` verification, plus atomic `TasksTx` crawl-job mirror commits (`v1.5.5 -> v1.5.6`)

PageSift `1.5.6` resolves the post-`1.5.5` mathematical, execution, evidence-state, and concurrency-safety defects identified during Loop review and macOS CI testing, without introducing unreleased post-`1.5` architecture.

## Highlights

- **Atomic `TasksTx` Job Mirror Commits (`pagesift-store`, `pagesift-api`)**: Introduces `TasksTx` (`Tasks::begin_tx` / `Tasks::atomic`) backed by `AtomicTx` so `jobs::mirror::write` commits page records and `done_set` updates in one all-or-nothing transaction, eliminating cross-thread race states between concurrent task writes and reads.
- **Observe Reliability Decoupling, Anchors & Coverage Integrity (`pagesift-store`, `pagesift-engine`, `pagesift-plan`)**: Separates `last_attempted_at_ms`, `last_valid_observed_at_ms`, and `last_substantive_change_at_ms` (`valid_observation_anchor_ms`) so failed or unreliable attempts no longer shorten the next observation interval; assesses HTTP and Browser capture reliability independently (`should_adopt_browser_escalation` rejects unreliable browser captures and censors `browser_gain` when rescuing an unreliable HTTP capture); and propagates both intra-tick `uncertain_observations` and persisted `last_observation_unreliable` / `TransientFailure` gaps into `CoverageReport` so unresolved uncertainty blocks `CompleteWithinScope`.
- **Periodic Learning, `Last-Modified`, Phase Isolation & Live Waterfill (`pagesift-stat`, `pagesift-store`, `pagesift-plan`, `pagesift-engine`)**: Wires HTTP `Last-Modified` headers (filtered via `validate_credible_last_modified` and `httpdate::parse_http_date` for future skew, stale unchanged headers, and dynamic wall-clock responses) into `FamilyObservation`, `InventoryObservation`, and `ResourceLearnStats`; invalidates stale detected periods on early changes, late changes, missed cycles, and prolonged outages (`update_period_observations`, `next_periodic_delay_guarded`); replaces cross-resource pooled timestamps with per-resource phase tracking plus shared `FamilyPeriodPrior` evaluated against real `now_ms`; removes the `!substantive_changed` Priority 1 block on periodic rescheduling; persists Lagrange `apply_waterfill_schedules_to_inventory` intervals to visited active `ResourceRecord.next_due_at_ms`; and deduplicates multi-wave `candidates_due` counts via `due_keys_seen`.
- **Adapt Execution, Shadow Pricing, Recovery & Transfer Isolation (`pagesift-plan`, `pagesift-engine`)**: Refreshes `AdaptDecision` per candidate (`refresh_candidate_decision`) against live `RenderStats::tab_utilization()` and remaining browser budget so `browser_escalation_permitted` constrains real browser execution rather than only changing a returned decision field; orders `DirectBrowser` SSR recovery probes ahead of validator checks and prevents single-step relocking via `probe_positive_streak`; fixes double consumption of triggering observations and clears `barrier_rate` / `seeded_*_mean` on negative-transfer rejection while keeping tenant-isolated failure accounting (`tenant_id`).
- **Evidence State Separation & Truncation Visibility (`pagesift-graph`, `pagesift-store`, `pagesift`, `pagesift-mcp`)**: Keeps `ClaimStatus::Active` (`verified_support_count`) distinct from `Unverified`/`EvidenceDegraded` (`unverified_support_count`, `unverified_distinct_sources`, `total_independent_sources`) in `FactCluster` built from claim lifecycles; surfaces `fact_clusters_truncated` from `build_conflicts_and_clusters_for_lifecycles_checked` through `SourceStateView`, CLI (`sync status` / `sync state`), and MCP output schemas; and introduces `ValueComparison::UnitOrCurrencyUnspecified` so `"UNKNOWN"` currency, `MoneyPeriod::Unknown`, or `unit: None` alone never emit false confirmed conflicts alongside real mismatches.

## Local Loop & End-to-End Evaluation (`loop_eval`)

Measured locally via `cargo run --profile release-fast -p pagesift-engine --example loop_eval` (Linux x86_64, local HTTP origins + 16 archived HTML snapshots; simulation/ablation metrics and real HTTP E2E runs reported separately):

- **S1 Periodic vs Aliased (synthetic regularity simulation, 18,000s horizon, true period `600 s`)**: Regularity scheduling achieves `63.8 s` mean detection lag across `33` checks (lower is better; Poisson baseline `206.0 s` across `27` checks, fixed-60s `300` checks) and rejects aliased coarse `600 s` polling on a `150 s` target (`aliased_coarse_polls_rejected_fake_period: true`).
- **S2 Drift, Embedded JSON & SSR Recovery**: Surprise forgetting drops burst-tier rates below 50% in `9` calm ticks (`13` baseline); on `5` real HTTP `__NEXT_DATA__` pages, Sync triggers `0` browser escalations (`5` in HTTP-only ablation); SPA-to-SSR migration recovers to HTTP in `2` probe rounds.
- **S3 Budget Waterfill & Live Shadow Pricing**: Theoretical tight-budget expected missed hazard drops from `852.24` (equal uniform intervals) to `25.87` (lower is better). In real HTTP `sync` E2E under tight budget and constrained browser quota (`real_sync_waterfill_*`, `real_sync_shadow_price_*`), hot vs cold due intervals separate to `30.0 s` vs `3,836.3 s`, and live shadow pricing caps browser renders at `2` while offloading `2` remaining decisions mid-tick.
- **S4 Transfer & Negative Rejection**: Positive transfer raises cold-start `http_sufficient` mean from `0.667` to `0.792`; negative transfer rejects after `2` local contradictions, restores posterior mean to `0.174` with `3.755` single-consumed local trials (zero double counting), and maintains `cross_tenant_leaked: false`.
- **S5 Unreliable Decode & Time Anchor Safety**: `2` corrupted response ticks preserve `3` `Unverified` claims with `0` false withdrawals, intact `ETag` baseline, `valid_time_anchor_preserved: true`, and `uncertain_blocks_complete_within_scope: true`.
- **S6 Evidence Currencies & Citations**: Outputs `["EUR", "UNKNOWN", "USD"]` with `1` `EUR`/`USD` mismatch conflict, `0` false conflicts on `"UNKNOWN"` currency alone, and `verified_support_count: 2` (`unverified_support_count: 0`, `independent_sources: 1`).
- **S7 Hub Co-Change & Archived Corpus (`16` pages × `3` sync ticks)**: Hub substantive update pulls forward `2` child pages; real corpus executes `51` requests with `28` HTTP `304 Not Modified` hits, `854` stored claims, `13,201,648` store bytes, and `854 ms` total wall time.
