# PageSift 0.81.5 Release Notes: Linux Builds Load on Older glibc

> **Release Version**: `v0.81.5`
> **Release Date**: 2026-10-31
> **License**: AGPL-3.0-only (Commercial licensing available)

---

## Overview

The Linux glibc builds of the Node binding (`@pagesift/node-linux-x64-gnu`,
`@pagesift/node-linux-arm64-gnu`) and the command-line binaries from 0.81.4 and earlier were compiled
on a glibc 2.39 system. They reference symbols from glibc 2.34 and 2.35, so they fail to load on older
distributions with `GLIBC_2.35 not found`. 0.81.5 compiles them in a glibc 2.28 environment and checks
the result before publishing. No API or configuration changes.

## What was wrong

For the x86_64 Node binding in 0.81.2 and 0.81.4, `objdump -T` showed these requirements:

| Symbols | glibc version |
|---|---|
| `pthread_create`, `dlopen` and related | 2.34 |
| `hypot` | 2.35 |
| `pidfd_spawnp`, `pidfd_getpid` (weak) | 2.39 |

The 2.34 and 2.35 symbols are what stop loading on a system with glibc 2.32. The Linux command-line
binary had the same requirement. The Python wheels were already built for `manylinux_2_28` and were not
affected. musl, macOS and Windows packages were not affected.

## What changed

- Linux gnu builds of the Node binding and the command-line binary (x86_64 and aarch64) are compiled in
  the `manylinux_2_28` container (glibc 2.28).
- `scripts/check_glibc.sh` reads the highest `GLIBC_x.y` a build requires and fails the release job above
  2.28.
- Release CI runs the full Node binding tests on Node 18, 20, 22, 24 and 26 on Linux x64 (glibc 2.28),
  and on Node 18 and 26 on the other platforms. A failure in any of them blocks publishing.

## Requirements

- Linux glibc builds: glibc 2.28 or newer. Official Node.js 18 to 26 binaries need glibc 2.28 as well.
- Node 18 or newer, as before.

## Verification

Checked on x86_64 with a binding built in the `manylinux_2_28` container:

- Highest glibc requirement: 2.28 for both the Node binding and the command-line binary.
- Node binding tests (38) pass on Node 18.20.8, 20.20.2, 22.23.4, 24.22.2 and 26.13.0 in AlmaLinux 8
  (glibc 2.28).
- The PGO training script runs to completion in the container.
- Not measured on aarch64 locally; the aarch64 builds go through the same glibc check in release CI.
- Benchmarks were not re-run; no benchmark numbers in the README or docs are new.
