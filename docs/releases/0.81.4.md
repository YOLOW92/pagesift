# PageSift 0.81.4 Release Notes: Dependency Security Update

> **Release Version**: `v0.81.4`
> **Release Date**: 2026-10-31
> **License**: AGPL-3.0-only (Commercial licensing available)

---

## Overview

0.81.4 only upgrades dependencies to fix four RustSec advisories. There are no API or configuration
changes; upgrading from 0.81.3 needs no other action.

## Fixed advisories

| Advisory | Crate | Issue | Fixed by |
|---|---|---|---|
| [RUSTSEC-2026-0384](https://rustsec.org/advisories/RUSTSEC-2026-0384) | tokio 1.54.0 | Race condition in `tokio::time::Interval` | tokio 1.54.1 |
| [RUSTSEC-2026-0391](https://rustsec.org/advisories/RUSTSEC-2026-0391) | zstd 0.13.3 | Data from an abandoned stream leaks into the next stream on a reused context | zstd 0.14.3 |
| [RUSTSEC-2026-0398](https://rustsec.org/advisories/RUSTSEC-2026-0398) | zstd-safe 7.3.0 | `Seekable::decompress` sets a `Vec` length beyond its capacity for offsets past the end | zstd-safe 8.2.0 |
| [RUSTSEC-2026-0403](https://rustsec.org/advisories/RUSTSEC-2026-0403) | zstd-safe 7.3.0 | Uninitialized memory exposed when streaming decompression of a legacy frame fails | zstd-safe 8.2.0 |

pagesift uses zstd to decode `Content-Encoding: zstd` HTTP responses (`pagesift-net`) and to compress
stored HTML snapshots (`pagesift-store`). Whether pagesift's own call paths reached the vulnerable code
was not analysed; the dependencies were upgraded regardless.

## Other changes

- Crates that required tokio 1.54.0 now require 1.54.1, so builds from crates.io also get the fix.
- `cargo deny` configuration: three workspace crates (`pagesift-fuzz`, `pagesift-office`,
  `pagesift-testkit`) were missing from the AGPL license exceptions and made the license check fail;
  they are now listed.

## Verification

- `cargo deny check`: advisories, bans, licenses and sources all pass.
- `pagesift-net` and `pagesift-store` test suites pass, including the zstd encode/decode tests; the
  whole workspace builds with all targets.
- Not re-run for this release: benchmarks. Only dependency versions changed; no benchmark numbers in
  the README or docs are new.
