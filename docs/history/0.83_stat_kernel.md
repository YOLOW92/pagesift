# 0.83 — Statistics kernel (`pagesift-stat`)

New crate `crates/pagesift-stat`, no dependencies. Every estimator implements `Stat` (`merge`, `encode`, `decode`);
merging is associative and order-independent, so threads, machines and time segments are combined the same way.
The only meta-parameter is the risk level `δ` (default 0.05).

Deviations from the original definitions are written in the module comments: Kaplan–Meier times are quantised to
relative error α so that merging is a bucket sum; the CUSUM uses the current segment's estimated mean and variance; the
shadow price uses the single-server form with total utilisation.

## Tests

`cargo test --release -p pagesift-stat`: 18 tests, each checking a property from the source:

- merge is associative and equals the batch result (moments, sketch, Kaplan–Meier, Count-Min / HyperLogLog);
- DDSketch quantiles stay within relative error α;
- Kaplan–Meier under independent censoring matches `e^{−t}` within 4 Greenwood standard errors, and `h(t, Δ)` matches the memoryless value;
- USL recovers λ, σ, κ and `N*` from synthetic data;
- Thompson sampling regret grows logarithmically on a synthetic Bernoulli bandit (10× horizon, < 3× regret);
- CUSUM false-alarm rate per observation is below δ on 200,000 stationary samples, and a +1σ step is found with the right sign;
- the method-of-moments prior recovers the population mean and strength, and one group with 10⁶ successes moves the mean by at most `1/groups`;
- calibration: logistic regression recovers coefficients; a calibrated model passes the gate and a reversed one does not;
- encode → decode round-trips for every stat and for a table; a version mismatch is rejected; a frozen table does not change.
