# 0.83 — Result-quality score: calibration check

**Goal.** Check whether the quality score (calibrated `P(result complete and usable)`, `crates/pagesift-plan/src/quality.rs`)
passes the calibration gate. Both conditions must hold on out-of-sample predictions:

- reliability: in every quantile bin, the mean prediction is consistent with the observed frequency (Wilson interval,
  Benjamini–Hochberg across bins, δ = 0.05);
- discrimination: the Brier score is significantly lower than a constant base-rate predictor (paired bootstrap, the
  one-sided upper bound of `Brier(model) − Brier(constant)` < 0).

Brier score: lower is better.

## Method

| Item | Value |
|---|---|
| Pages | AEB 181, WCXB test 511, WebMainBench 545, Firecrawl 597 = 1,834 (1,828 with reference text) |
| Extractor | `pagesift_content::process` with default options (HTTP path only; no browser candidates) |
| Recall | the same for all four sets: `wcxb.word_f1` recall (lower-case `\w+` tokens, multiset overlap / reference tokens) of the output's plain text against the set's reference text |
| Label | positive if recall ≥ that set's `q(δ)` recall and recall > 0 |
| Features | 12 that vary (`FEATURE_NAMES`): text weight, HTML bytes, coverage measured / share, output share of page text, root in comments, comment ratio, barrier confidence, article mode, headings, paragraphs, link-text share |
| Score | logistic regression with Firth's bias-reduced likelihood (Firth 1993) |
| Calibration | isotonic regression (PAV) on out-of-fold scores of two cross-fitted score models; prediction = mean of the calibrated probabilities of both models (`QualityModel::fit_cross`) |
| Evaluation | three folds by FNV-1a hash of the page id; each fold is predicted by a model fitted on the other two; the gate is applied once to the pooled out-of-fold predictions of all 1,828 pages |

Script: `benchmarks/history/0.83/run.sh` (`label.py`, examples `quality_data` and `quality_fit`).
Results: `benchmarks/history/0.83/results/20261102-165739/`.

Failures are concentrated in the lowest quarter of scores and the other three quarters are nearly flat (0.982–0.985
observed). A smooth calibration curve cannot fit that step; isotonic regression can.
