### 本轮唯一的算法改动（重大 BUG 修复 + 一处策略默认值）

1. **修复 B 级 BUG（资源不收敛）**：嵌套 `<table>` 让 `markdown::Renderer` 表格渲染路径互相回流，
   单页（`help.windev.com/?1013105`，241 个 table、最深 27 层）无限空转、单核 100% 且无输出。
   引入 `flat` 模式：单元格/排版表内部不再展开内层表格，只透传文字。该页从「永不结束」变为 **3.2 ms / 39 KB**，
   `pagesift-content` **117 个测试全过**。不修则全量跑不完、且卡住的页面会被静默排除导致分数虚高。
2. **正文定位默认启用**：原实现仅在 `metadata.is_article` 时尝试文章模式，现对所有页面尝试，
   失败仍按原有三道兜底回退整页。800 页留出样本上 F1 `0.5866 → 0.6413`。

## 3. olmOCR-bench PDF

**口径与冻结件**：`allenai/olmOCR-bench`（HF，`bench_data/**`）；PDF 用 `pagesift-pdf` 的
`pdf_dir_mt` 转 Markdown（1,403 文件、0 失败、4.24 MB、约 3,300 页/s）；判定复用官方
`olmocr/bench/tests.py`（`f7cfe4c2…`）的 `load_tests` + `test.run`，按 jsonl 文件分组的宏平均
（与官方 benchmark.py 的聚合口径一致；仅跳过 HTML 报告生成，不影响分数）。

| jsonl | 项数 | 通过率 |
| :--- | ---: | ---: |
| arxiv_math | 2,927 | 0.4086 |
| headers_footers | 760 | **0.6829** |
| long_tiny_text | 442 | 0.4525 |
| multi_column | 884 | **0.6629** |
| old_scans | 526 | **0.1331** |
| old_scans_math | 458 | **0.0000** |
| table_tests | 1,022 | 0.5802 |
| **宏平均** | **7,019** | **0.4172** |

按测试类型：`absent 0.7084` / `order 0.5523` / `table 0.5814` / `baseline 0.6667` /
`math 0.3533` / `present 0.2774`。

**诚实结论**：`old_scans`（0.1331）与 `old_scans_math`（0.0000）接近失效，根因是
**PageSift 不含 OCR**，纯扫描件没有文本层可抽。这两类合计 984 项（占 14%），
拉低整体。它不是抽取质量问题，而是能力边界；若要覆盖需接入 OCR 引擎，本轮不做。

## 5. 复现命令

```bash
# 1 WebMainBench
BIN=benchmarks/web-extraction/webmainbench/target/release/pagesift-p4-2-webmainbench
$BIN benchmarks/data/p4_2_webmainbench/webmainbench.jsonl $OUT/v2/pred_full.parts.jsonl 128 \
     --hard-timeout-secs 180 --soft-warn-secs 60
benchmarks/common/vendor/.venv/bin/python benchmarks/web-extraction/webmainbench/finalize.py \
     benchmarks/data/p4_2_webmainbench/webmainbench.jsonl $OUT/v2/pred_full.parts.jsonl $OUT/v2/pred_full.jsonl
benchmarks/common/vendor/.venv/bin/python benchmarks/web-extraction/webmainbench/score_full.py \
     benchmarks/data/p4_2_webmainbench/webmainbench.jsonl $OUT/v2/pred_full.jsonl \
     benchmarks/web-extraction/vendor/MinerU-HTML $OUT/v2/score --workers 64

# 2 WCEB
benchmarks/common/vendor/.venv/bin/python benchmarks/web-extraction/webmainbench/wceb_run.py \
     benchmarks/common/vendor/WCEB/datasets/combined $OUTW/pred $BIN 64
benchmarks/common/vendor/.venv/bin/python benchmarks/web-extraction/webmainbench/wceb_score.py \
     benchmarks/common/vendor/WCEB/datasets/combined $OUTW/pred $OUTW/score 64

# 3 olmOCR-bench
target/release/examples/pdf_dir_mt benchmarks/data/olmocr/bench/bench_data/pdfs $OUTO/md 96
benchmarks/common/vendor/.venv/bin/python benchmarks/web-extraction/webmainbench/olmocr_score.py \
     benchmarks/data/olmocr/bench/bench_data $OUTO/md $OUTO/score 24

# 4 WCXB
benchmarks/common/vendor/.venv/bin/python benchmarks/common/fresh/wcxb.py prepare benchmarks/data/wcxb $OUTX/work all
target/release/examples/extract_jsonl $OUTX/work/manifest.jsonl $OUTX/pagesift.jsonl
benchmarks/common/vendor/.venv/bin/python benchmarks/common/fresh/wcxb.py score benchmarks/data/wcxb $OUTX/work all $OUTX/pagesift.jsonl
```

Python 依赖：`rouge_score jieba rapidfuzz levenshtein numpy bs4 lxml jsonlines apted openai
python-dotenv nltk(hyphen) fuzzysearch playwright(pip)+chromium pypdf tqdm huggingface_hub`。
